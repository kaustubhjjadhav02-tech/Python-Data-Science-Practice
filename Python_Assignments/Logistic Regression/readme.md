# 📊 Logistic Regression – Classification & Deployment

This project focuses on building, evaluating, and interpreting a **Logistic Regression model** for binary classification. It covers the complete machine learning workflow—from data exploration and preprocessing to model evaluation and deployment using Streamlit.

---

## 🎯 Objective
The objective of this assignment is to apply logistic regression to predict a binary outcome (such as survival probability) by analyzing input features, evaluating model performance, and interpreting feature importance.

---

## 📁 Project Workflow

### **1. Data Exploration**
- Load the dataset and perform Exploratory Data Analysis (EDA).
- Examine feature types and summary statistics.
- Create visualizations such as:
  - Histograms
  - Box plots
  - Pair plots
- Analyze distributions, patterns, and correlations among features.

---

### **2. Data Preprocessing**
- Handle missing values using appropriate techniques (e.g., imputation).
- Encode categorical variables to numerical form.
- Prepare the dataset for model training.

---

### **3. Model Building**
- Build a Logistic Regression model using Python libraries (e.g., `scikit-learn`).
- Split data into training and testing sets.
- Train the model on the training dataset.

---

### **4. Model Evaluation**
Evaluate model performance using standard classification metrics:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC score

Visualize the **ROC curve** to assess classification performance.

---

### **5. Model Interpretation**
- Interpret the coefficients of the logistic regression model.
- Discuss the importance and impact of each feature.
- Explain how features influence the predicted probability of the target class.

---

### **6. Model Deployment (Streamlit)**
- Deploy the trained logistic regression model using **Streamlit**.
- Create a user interface that allows input of feature values.
- Display predicted outcomes interactively.
- Deployment can be done:
  - Locally
  - Online using **Streamlit Community Cloud**

📖 Reference:  
https://docs.streamlit.io/streamlit-community-cloud/deploy-your-app
