# Multiple Linear Regression (MLR)

## Objective
The objective of this assignment is to build and evaluate a **Multiple Linear Regression (MLR)** model to predict the **price of a Toyota Corolla** based on various vehicle attributes. The task involves data exploration, preprocessing, model building, evaluation, and regularization techniques.

---

## Dataset Description
The dataset contains the following variables:

- **Age**: Age of the car in years  
- **KM**: Accumulated kilometers on the odometer  
- **FuelType**: Type of fuel used (Petrol, Diesel, CNG)  
- **HP**: Horsepower of the vehicle  
- **Automatic**: Transmission type (Yes = 1, No = 0)  
- **CC**: Engine cylinder capacity (in cubic centimeters)  
- **Doors**: Number of doors  
- **Weight**: Weight of the car in kilograms  
- **Quarterly_Tax**: Quarterly road tax  
- **Price**: Offer price of the car in Euros (target variable)

---

## Tasks Performed

1. Conduct **Exploratory Data Analysis (EDA)** to understand data distribution, relationships, and patterns.
2. Perform **data preprocessing**, including encoding categorical variables and handling scaling if required.
3. Split the dataset into **training (80%)** and **testing (20%)** sets.
4. Build and train **multiple linear regression models** and interpret model coefficients.
5. Evaluate model performance using appropriate **regression metrics**.
6. Apply **Ridge and Lasso regression** to address multicollinearity and improve model generalization.

---

## Interview Questions Addressed

- What is **Normalization and Standardization**, and why are they important?
- How can **multicollinearity** be detected and handled in multiple linear regression?
- What assumptions are made in linear regression, and how do they impact model performance?

---

## Conclusion
This assignment demonstrates how multiple linear regression can be effectively applied to real-world pricing problems. By combining EDA, proper preprocessing, model evaluation, and regularization techniques, a robust and interpretable predictive model is developed.
